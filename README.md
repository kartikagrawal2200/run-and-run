## 🕹️ Controls

| Action | Keyboard | Touch / Mobile |
| :--- | :--- | :--- |
| **Change Lanes** | `A` / `D` or `←` / `→` | Swipe Left / Right or tap on-screen arrows |
| **Jump** | `W` / `↑` / `Space` | Swipe Up (Jump onto train roofs & over barriers) |
| **Roll / Slide** | `S` / `↓` | Swipe Down (Slide under low overhead gantries) |
| **Activate Hoverboard** | Double Tap or Space | Double-tap screen or tap HUD board icon |
| **Pause Game** | `P` or `Esc` | Tap ⏸ pause button in HUD |

## ✨ Features

- **True 3D Perspective**: Custom volumetric rendering for 3D trains, tracks, ramps, and barriers.
- **Dynamic Procedural Audio**: Interactive Web Audio API music synth engine with customizable BGM and SFX.
- **Upgrades & Power-Ups**: Jetpacks, Coin Magnets, 2X Multipliers, Super Sneakers, and Hoverboards with crash protection.
- **Daily Missions & Trivia**: In-game achievements, multiplier rank progression, and runner trivia challenges.
- **PWA & Mobile Ready**: Full touch/swipe support, offline caching, and responsive full-screen scaling.
