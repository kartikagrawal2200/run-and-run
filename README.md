# 🏃 Run & Run - Cyber Endless Arcade

An adrenaline-fueled, synthwave-infused cyberpunk endless runner web game.

🎮 **Play Online**: [https://kartikagrawal2200.github.io/run-and-run/](https://kartikagrawal2200.github.io/run-and-run/)

---

## 🕹️ Controls

| Action | Keyboard | Touch / Mobile |
| :--- | :--- | :--- |
| **Switch Lanes** | `A` / `D` or `←` / `→` | Tap `◀` / `▶` on screen or swipe left/right |
| **Jump** | `W` / `↑` / `Space` | Tap `▲ JUMP` on screen or swipe up |
| **Slide** | `S` / `↓` | Tap `▼ SLIDE` on screen or swipe down |
| **Pause** | `P` or `Esc` | Tap `⏸` top-right button |
| **Toggle Music** | - | Tap `🎵` top-right button |
| **Toggle Sound FX** | - | Tap `🔊` top-right button |

---

## ✨ Features
- **Procedural Synthwave Soundtrack**: 124 BPM retro beats with bassline, drums, and arpeggios synthesized in pure Web Audio API (zero audio files to download).
- **Spaced Obstacle Pacing**: Balanced difficulty with generous reaction time.
- **Dynamic Zones**: Cycles across futuristic cityscapes (Downtown Matrix, Sunset Highway, Toxic Core, Neon Desert, Glitch Void).
- **Powerups**: Magnet 🧲, 2X Score Multiplier ⭐, Energy Shield 🛡️.
- **Responsive**: Auto-scales to fit mobile phones, tablets, and desktop displays.
